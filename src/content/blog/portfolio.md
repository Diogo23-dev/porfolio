# Création de mon portfolio développeur

## Présentation

Ce projet consiste à créer mon portfolio personnel afin de présenter mon parcours, mes compétences techniques et mes différents projets.

Le portfolio constitue ma vitrine professionnelle et permet aux recruteurs ou aux clients de découvrir rapidement mon profil et mes réalisations.

## Aperçu du portfolio

![Aperçu de mon portfolio](/porfolio/portfolio.png)

## Objectifs

- Présenter mon parcours et mes compétences.
- Mettre en valeur mes projets.
- Permettre aux visiteurs de télécharger mon CV.
- Faciliter la prise de contact.
- Disposer d'une présence professionnelle en ligne.

## Structure du portfolio

Le portfolio est organisé autour de plusieurs sections :

- Accueil
- Compétences
- Projets
- Contact
- Téléchargement du CV

## Technologies utilisées

### HTML

HTML est utilisé pour structurer les différentes parties du site.

### CSS

CSS permet de construire l'identité visuelle du portfolio et son adaptation aux différentes tailles d'écran.

### JavaScript

JavaScript est utilisé pour les interactions du site, notamment la navigation, le changement de thème et différents comportements côté client.

### Git et GitHub

Git est utilisé pour versionner le projet et GitHub permet d'héberger le dépôt et de publier le site avec GitHub Pages.

## Déploiement

Le portfolio original est publié avec GitHub Pages.

## Évolution vers Astro

Le portfolio évolue progressivement vers Astro afin d'améliorer son organisation et sa maintenabilité.

L'objectif est notamment de transformer chaque projet présenté dans le portfolio en une documentation accessible depuis sa propre page.

Le contenu de ces documentations sera écrit en Markdown et transformé automatiquement en pages web par Astro.

## Prochaine évolution

Chaque projet du portfolio disposera progressivement de sa propre documentation, présentant :

- le contexte du projet ;
- les objectifs ;
- les technologies utilisées ;
- la conception ;
- le développement ;
- les difficultés rencontrées ;
- les solutions apportées ;
- le résultat obtenu ;
- les améliorations futures.
